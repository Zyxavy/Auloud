To rebuild the full APK yourself from that source:

1. Install JDK 17 and the Android SDK (compileSdk 36; minSdk stays 24).
2. Check out the tagged source named in the release notes.
3. The exact speech runtime is pinned and needs no manual download:
   com.github.k2-fsa.sherpa-onnx:sherpa-onnx:1.13.8, resolved from
   https://jitpack.io (declared in player/settings.gradle.kts, pinned
   in player/gradle/libs.versions.toml). Its AAR carries the native
   libraries (libonnxruntime.so plus the sherpa libs with statically
   linked espeak-ng) for arm64-v8a, armeabi-v7a, x86 and x86_64.
4. From the player/ directory run:
   gradlew.bat :app:assembleFullRelease
   (a release signing key is needed for a distributable signature, see
   docs/archive/v1/ReleaseSigning.md; without it the build signs with
   the debug key and prints a warning).
5. Verify the result with:
   gradlew.bat :app:assembleCoreDebug :app:assembleFullDebug :app:licenseScan
   (core must show no sherpa/onnxruntime/espeak files; full must show
   the sherpa files plus these three asset files).
